# 量化 + Hash Reuse 联合实验命令

本文档只保留当前主线命令，避免和 AWQ / Score 文档重复。

## 1. 联合实验在做什么

`reuse_real_quant` 同时评估：

```text
1. Hash reuse 命中多少节点；
2. 未命中的节点再走 W4A8 / W4A4 / FP 路径；
3. 最终 cost、acc、drop、final error。
```

执行逻辑：

```text
node v
  -> 如果 hash reuse 命中并通过 gate:
         复用已有 embedding，cost = 0
  -> 否则:
         按 real quant policy 选择 W4A8 / W4A4 / FP
```

因此表里的 W4A4 / W4A8 / FP 百分比是全图实际计算比例，不是只在 miss 节点内的比例。

## 2. 前置条件

需要先生成 embedding pools：

```text
cache_data/{dataset}_{model}_oracle_W4A16.pt
cache_data/{dataset}_{model}_oracle_W4A8.pt
cache_data/{dataset}_{model}_oracle_W4A4.pt
```

ST / Cora + PubMed：

```bash
python -m GraphhopSimhash.generate_real_quant_pools \
  --datasets cora pubmed \
  --llm_name ST \
  --configs W4A16 W4A8 W4A4 \
  --batch_size 64 \
  --awq_calib_samples 16 \
  --awq_seqlen 128 \
  --overwrite
```

## 3. Cora 联合实验

```bash
python -m GraphhopSimhash \
  --datasets cora \
  --runs 3 \
  --experiment_suite reuse_real_quant \
  --real_quant_policy_suite w4a8_budget \
  --real_quant_model_name ST \
  --real_quant_fp_tag W4A16 \
  --real_quant_int8_tag W4A8 \
  --real_quant_int4_tag W4A4 \
  --real_quant_fp_ratio 0.0 \
  --real_quant_int8_ratio 0.20 \
  --real_quant_error_norm 1.0 \
  --learned_hash_epochs 10 \
  --learned_hash_dim 128 \
  --hamming_only_acceptor \
  --enable_score_gate \
  --main_hash_head_bits 16 16 16 16 16 16 16 16 \
  --route_min_support_hits 3
```

## 5. 关键参数

### `--experiment_suite reuse_real_quant`

打开 hash reuse + real quant 联合路径。

### `--real_quant_policy_suite w4a8_budget`

使用当前主线量化预算表：

```text
AllFP
UniformW4A8
UniformW4A4
RandomTopK_W4A8
DegreeTopK_W4A8
TSERTopK_W4A8
```

### `--real_quant_fp_tag W4A16`

使用 AWQ-family reference。注意它不是干净 FP16，而是：

```text
官方 AWQ W4 weight + FP16 activation
```

如果要用完全 FP16 reference，需要先生成 `FP16` pool，并把 tag 改成 `FP16`。

### `--real_quant_int8_tag W4A8`

W4 weight + A8 activation 的安全低精度路径。

### `--real_quant_int4_tag W4A4`

W4 weight + A4 activation 的激进路径。

### `--real_quant_int8_ratio 0.20`

在未复用节点的量化路由里，保护 20% 高风险节点走 W4A8，其余走 W4A4。

### `--enable_score_gate`

打开 TSER reuse gate。没有它时，hash reuse 更激进，reuse 更高但 drop 通常更大。

### `--route_min_support_hits 3`

要求候选至少有更强的 route support，减少偶然 hash collision。

## 6. 输出表怎么读

典型列：

```text
Reuse %
    全图有多少节点复用了已有 embedding。

W4A4 % / W4A8 % / FP %
    全图实际计算路径占比。

Cost
    近似计算成本。

Acc / Drop %
    最终 GNN 分类精度和相对 baseline 掉点。

FinalErr
    reuse + quant 之后最终 embedding 与 reference 的平均误差。

Reuse n/d
    reuse 节点数 / 总节点数。
```

重要：`AllFP` 在 `reuse_real_quant` 里也可能有 drop，因为它仍然包含 hash reuse。

```text
AllFP:
    reuse hit 节点复用 cache；
    reuse miss 节点走 FP；
    drop 来自 reuse，不是量化。
```

## 7. 和 `real_quant_ablation` 的区别

```text
real_quant_ablation:
    不做 hash reuse；
    每个节点都实际走 FP / W4A8 / W4A4 路径；
    用来评估量化 backend 和路由策略。

reuse_real_quant:
    先做 hash reuse；
    只有 miss 节点才走真实量化路径；
    用来评估全栈系统成本与精度。
```

## 8. 建议实验顺序

```text
1. 先跑 real_quant_ablation：
       确认 W4A8/W4A4 backend 是否可用。

2. 再跑 score_ablation：
       确认 TSER gate 对 reuse/drop 的作用。

3. 最后跑 reuse_real_quant：
       看 reuse + quant 的全栈收益。
```

如果 W4A4 backend 本身掉点很大，联合实验的结论会被低精度 backend 拖累。
